# CSJ 話速 census — 結果と、CSJ メタデータの罠（2026-07-09）

生成: `cadence_csj_speech_rate_census_v6.ipynb` / `cadence_csj_fetch_xml_for_census_v3.ipynb`
母集団: 集合評定 **3箇所呈示 177 講演** − **`A01M0035`**（`Phone` ラベルなし = コア外）
→ **176 講演（A:70 / S:106）× 3 聴取単位 × 10 評定者 = 5,280 行 / 528 単位**

---

## 0. 一行で

**「話速」は二つの別物である。** 人間が「速い」と感じているのはポーズを含んだ *発話速度* であって、
*調音速度* ではない。品質ゲートが測るべきは後者、cadence が学習すべきは前者との差分（間の取り方）。

## 1. 主要な結果

### 1.1 分母の当否 — `span` が知覚を、`speech` が品質を測る

| 分母 | 定義 | Spearman ρ（速さ感因子と） |
|---|---|---:|
| `speech_ipu` | Σ(実発話区間)。`PAUSE_MIN` 未満の無音は含む | **+0.653** |
| `speech_strict` | Σ(非無音 Phone) のみ | +0.659 |
| `span` | 末尾 − 先頭。ポーズ込み。**CV のクリップ長に対応** | **+0.828** |

ジャンル内でも成立（A: speech +0.610 / span +0.751、S: +0.558 / +0.789）。
講演レベル・単独評定 `[$53]` でも同じ向き（`all`: +0.414 vs +0.592）。**交絡ではない。**

決定的なのはラダーの幅。`[$53] 発話スピード` の 2→5 で:

| | 2 | 5 | 幅 |
|---|---:|---:|---:|
| 調音速度 `rate_speech` | 7.82 | 8.74 | +0.92（**+11.7%**） |
| 発話速度 `rate_span` | 5.20 | 7.38 | +2.18（**+41.9%**） |

**調音は 12% しか動かないのに、ポーズ込みは 42% 動く（3.6 倍）。**
`impression.pdf` の速さ感因子に `せわしげな—のんきな` / `落ち着きのない—落ち着きのある` が
同居しているのは偶然ではない。

**帰結（r2 Tier0）**: 指標を 2 本に割る。1 本にまとめない。

| 指標 | 定義 | 何を測るか | 用途 |
|---|---|---|---|
| `articulation_rate` | mora / 実発話長 | 書き起こしと音の整合 | **品質ゲート** |
| `speaking_rate` | mora / クリップ長 | 話し方の印象 | 記述のみ |
| `pause_ratio` | 1 − 実発話長/クリップ長 | 間の取り方 | **cadence が保存すべき情報。落とさない** |

### 1.2 分子 — フィラーは話速として知覚されている

| 分子 | ρ |
|---|---:|
| **`all`（全モーラ）** | **+0.653** |
| `nofil`（− Filler） | +0.631 |
| `nofil_nodis`（− Filler, Disfluency, Disfluency2） | +0.631 |
| `speech_only`（+ − Laughing） | +0.643 |

**除外するほど相関が落ちる。人は「えー」を数えている。**

ただし用途で割れる。**知覚の記述 → `all`。CV との比較 → `nofil`**
（CV は朗読でフィラーが存在せず、抜かないと同じものを測っていない）。

区間タグ内モーラ（176 講演）: Filler **6.76%** / Incorrect 2.33% / Disfluency 0.98% / Laughing 0.65% /
Alphabet 0.47% / その他（Mask, Uncertain, Whisper, Quote, Foreign, B, Kanji, POccurrence_）< 0.3%

### 1.3 分布

CSJ 自発音声・528 単位:

| | `rate_speech`（調音） | `rate_nofil` | `rate_span`（発話） | `rate_span_nofil` |
|---|---:|---:|---:|---:|
| p50 | 8.40 | 7.89 | 6.54 | 6.12 |
| p90 | 9.63 | 9.12 | 8.04 | 7.58 |
| p95 | 10.14 | 9.56 | 8.43 | 7.87 |
| p99 | 10.75 | 10.27 | 9.02 | 8.65 |
| **p100** | **11.18** | 10.78 | 9.64 | 9.41 |

- `speech/span` 比: 中央値 **1.273**（p5 1.138 / p95 1.604）
- `speech_ipu / speech_strict`: 中央値 **1.0207**（短い無音の寄与はわずか）
- `pause_ratio`: 中央値 0.215（**A 0.186 / S 0.242**）。A（学会・会場ライブ）の方が間が短い

参考 cv_r1（MFA モーラ / クリップ長 = `speaking_rate` 相当）: 中央値 7.71 / p95 10.4 / p99 12.5

**注意**: 聴取単位は「10 秒以上のポーズを含む箇所は対象としない」（`impression.pdf` §3.2.1）で
切り出されている。単位レベルの `pause_ratio` は**ポーズを刈り込んだ標本**。

### 1.4 `cv_0155` は話者特性ではなく測定異常

`cv_0155`: 42 本中 26 本が旗、`speaking_rate` 中央値 **13.1 mora/s**（クリップ長基準）。

CSJ の `speech/span` 比 1.273 を当てると調音速度 **≈ 16.7 mora/s**。
CSJ 528 単位の調音速度の最大値は **11.18**。その **1.49 倍**。
CV のクリップには収録の余白（`pad`）が入るので、これは**下限**である。

**日本語話者が持続的に出せる調音速度ではない。**
話者ぐるみ 26/42 本という出方も、分散の裾ではなく話者単位のメタデータ不整合を示唆する。

→ **`cv_0155` / `cv_0191` / `cv_0267` は保つべき多様性ではない。落とすべき異常。**
（6 月から保留していた「品質ゲートで落とすもの vs cadence が学習すべき多様性」の切り分け、確定）

**`<3 mora/s` の旗（cv_r1 で 134 本）は分母のアーティファクト。**
CSJ の `rate_span` p50 が 6.54。分母がクリップ長で収録の余白が数秒あれば、短語のクリップは容易に 3 を割る。
実発話長で測れば消える。→ **旗を廃止**し、遅い側は `n_mora` の下限で捕まえる。

### 1.5 Tier0 閾値（暫定・CV 側の実測待ち）

```
articulation_rate = mora / 実発話長          ← CV では未計算。MFA TextGrid から導出すること
```

| 旗 | 閾値 | 根拠 |
|---|---|---|
| 早口 | `articulation_rate > 11.7` | CSJ 自発の p100 = 11.18。余裕 5% |
| 遅すぎ | **廃止** | 分母のアーティファクト |
| 話者ぐるみ | 話者中央値 > 10.8 | CSJ p99 = 10.75 を超える話者は分布外 |

**前提**: CV の `articulation_rate` はまだ無い。MFA の TextGrid（11,011 uid を完全被覆）から
`sil` / `sp` / `''` を除いた発話区間長を積む。これが `dataset_tools` の最初の関数。

CSJ 側は `Phone`（人手ラベル）、CV 側は TextGrid（MFA 推定）。**同じ指標を二つの経路で**出す
（`MoraProvider` と同じ非対称 → `SpeechIntervalProvider` として切る）。

**ただし CSJ を「正解」として扱えない**: `EndTimeUncertain` が **14.3%**。
人手ラベルでも 7 個に 1 個は境界が揺れている。

## 2. v4（IPU ベース）を破棄した経緯 — `Phone` を使う理由

当初 `Σ(IPU 長)` を実発話長とした。**IPU は実発話区間ではなかった。**

| 症状 | 実測 |
|---|---|
| IPU 間ギャップに時間閾値の構造が無い | p5 = 0.076 s / p50 = 0.407 s |
| **負のギャップ**（IPU の時刻が重なる） | **1,862 / 57,296（3.25%）**。うち `-1 ≤ gap < 0` が 863（中央値 −0.467 s） |
| `IPUEndTime` の桁破損 | **3 本**（例 `A02F0038` IPU `0323`: `00981.173` → `11181.173`） |
| `Channel` の混在か？ | 否。全 talk 単一（`L`） |
| `Σ Phone / Σ IPU` | **0.9484** → IPU 長は実発話長を **5.2% 過大評価** |

→ IPU は**転記単位**であって「ポーズで区切られた無音単位」ではない。`Σ(IPU 長)` は二重計上を含む。

**`Phone`（人手の分節音ラベル、時刻付き）に切り替え。** `Phone` の時刻はほぼ完全に単調
（非単調 4 / 1,843,811、最大逆行 94 ms = IPU 境界の丸め誤差）。ソートで解消し、結果に影響しない。

**`IPUID` は健全**（連番、`diff != 1` がゼロ）なので、
`impression.csv` の `START` / `END` は **「どの `Phone` が属するか」の索引としてのみ**使う。時刻は `Phone` から取る。

数値の変化: 調音 p100 `10.95 → 11.18`（+2.1%）、`speech/span` 比 `1.226 → 1.273`。
**`span` 優位（ρ 0.828 vs 0.653）は不動。** `span` は先頭〜末尾なので重なりの影響を受けない。

## 3. `SclS`（閉鎖）を無音扱いしてはいけない

`PhoneClass = 'others'` は 355,864 個（Phone − Phoneme = 1,959 が 1 講演で一致）。**中身が別物。**

| ラベル | 個数 | 個数比 | dur 中央 | 直後 | 判定 |
|---|---:|---:|---:|---|---|
| `SclS` | 289,066 | 15.68% | 0.041s | `k` / `t` / `d` / `g` / `c` | **閉鎖（調音の一部）→ 発話** |
| `SsvS` | 29,801 | 1.62% | 0.027s | `SclS` 105 / `Q` 7 | 促音の前置区間 → 発話 |
| `SpzS` | 25,822 | 1.40% | 0.087s | 散らばる | **ポーズ → 無音** |
| `SbS` | 703 | 0.04% | 0.138s | `SpzS` | **息継ぎ → 無音** |
| `SuvS` / `SfvS` / `S?S` / `SNS` / `SfrS` | 8,480 | 0.44% | — | — | **正体不明 → 発話扱い（下記）** |

**無音 = `SpzS` / `SbS` のみ。時間で Σ Phone の 2.36%。**

MFA の TextGrid では閉鎖は `k` の区間に**畳み込まれている**。
CSJ で `others` を全部抜くと個数で 15.7%、時間で 11〜12% を失い、**CSJ だけ調音速度が 12% 高く出る**。
`p100` が 11.18 → 12.5 程度になり、`cv_0155` の判定が変わりかねなかった。

**`dur = 0` の `SclS` が 13,114 / 289,066（4.5%）** — 閉鎖が観測されない /k/ 等。正常。
異常判定から除外すること（`PhoneClass != 'others'` に限る）。

### 3.1 `AMBIG` の扱いは恣意的でない — 感度分析で決めた

`SuvS` / `SfvS` / `S?S` / `SNS` / `SfrS` は計 8,480 個（0.44%）、時間で **0.63%**。正体不明。

| | ρ | p100 |
|---|---:|---:|
| **発話に含める（既定）** | **+0.653** | 11.18 |
| 無音として除く | +0.634 | 11.20 |

**除くと人手評定との相関が下がる。** → 発話扱いが正しい。差は中央値 0.021 mora/s。
`SfrS` はプローブ 6 講演に現れなかったが、追加しても数値は 1 桁も動かない。

### 3.2 `EndTimeUncertain` は 14.3%

境界が不確実とラベルされた `Phone` が **263,702 / 1,843,811**。
これを多く含む単位（上位 10%）を除くと ρ は 0.653 → **0.629 に下がる**。
不確実な境界がノイズを増やしていたのではない。除外の必要なし。

**人手ラベルでも 7 個に 1 個は境界が揺れる。** MFA 推定と比べるときの下限精度。

### 4.1 とくに危険なのは #6

素直に表 4 を読むと `8 − x` の反転が要るように見える。実際には不要。
反転すると相関の符号が逆転し（ρ = −0.828）、**大きさは変わらないので気づきにくい**。

検算: `A09`–`A11` の**生値**と `rate_span` の ρ が +0.850 / +0.830 / +0.744。全部正。
講演レベルの `[$53]`（1=遅い…5=速い）とも正の相関。

### 4.2 `A12` は速さ感の主指標から外す

`A12 落ち着きのない—落ち着きのある` は速さとの ρ が **+0.197**（他は +0.60〜+0.68）。
`A09`/`A10` との項目間相関も 0.15〜0.33。
`impression.pdf` 表 1 の因子パターン（速さ感への負荷 **0.571**、`上手さ` に **−0.389** の交差負荷）と符合する。
**数字が文書と一致した唯一の例。**

主指標 = `A09`–`A11` の生値平均（行レベル項目間相関 0.71〜0.82）。

### 4.3 母集団の仕分けキーは `[$64]` ではなく `[$72]`

`[$72] 集合印象評定` = `3箇所呈示`（177）/ `1箇所呈示`（24、ウォームアップ・再掲、非コア）/ `なし`。
`[$64]`（コア）を使うと `A01M0035` を落とし、非コアの 24 を混ぜる。

`impression.csv` の行数 5,568 のうち 18 行は再掲による重複。
`(SPEECH, START, END, RATER)` で除去 → 5,550。3箇所呈示に限定 → 5,310。
さらに `Phone` を持つ 176 講演に限定 → **5,280 = 176 × 3 × 10**。

### 4.4 記録票 ver1.0（20 講演）は `[$53]` も `[$54]` も欠測

`[$73]` パターン 1。話速の教師も明瞭さの品質プロキシも**同時に**欠ける。
これは品質ではなく **収録時期による欠測**。「悪い」のではなく「評定が無い」。

`A01M0035` も ver1.0。**コア外・3箇所呈示・`Phone` なし・`[$53]` 欠測が 4 つ揃う。**
初期に収録された講演が一括して例外的である。

`cadence_csj_speaker_selection.ipynb` は `mean_clarity` が nan の話者を
`nan >= CLARITY_MIN` = False で**無言に除外**している（→ 選定監査ノート）。

## 5. XML 構造（確認済み）

- `Mora` の親は常に `TransSUW`
- **`NonLinguisticSound` は `Mora` を含まない**（`MoraID` を持つ別要素）→ 分子は `.//Mora` でよい
- `IPU`: `IPUID`（4 桁ゼロ埋め・連番）/ `IPUStartTime` / `IPUEndTime`（**時刻は信用できない**）/ `Channel`（全て `L`）
- `Phone`: `PhoneID` / `PhoneEntity` / `PhoneClass` / `PhoneStartTime` / `PhoneEndTime` / `EndTimeUncertain`
  - `PhoneClass` ∈ {`vowel`, `consonant`, `special`, `others`}
  - `Phone` は **コア講演にのみ**付与（177 講演中 `A01M0035` のみゼロ）
- `Tag*Start` / `Tag*End` は **`TransSUW` と `Mora` の両方**に載る
  - `TransSUW`: Filler / Disfluency / Disfluency2 / Incorrect / Alphabet / Mask / Quote / Uncertain / Foreign / B / Kanji
  - `Mora`: Laughing / Whisper / Uncertain / POccurrence_（値は時刻。Start と End が同一 Mora）
- **プローブ（少数講演）では 4 タグを取りこぼした**（`Foreign` / `B` / `Kanji` / `SfrS`）
  → **標本でスキーマを決めない。** 全講演を生バイト列で走査して属性名を列挙すること
- 音声は配布 **16 kHz**（収録は 48 kHz / DAT / ヘッドセット CROWN CM-311a）
  → 実効帯域は全講演 8 k で頭打ち。**帯域による Tier0 較正は CSJ では不可能**
  → mean/max 音量比も、マイク距離が一定なので `cv_0007` 型は原理的に起きない

## 7. 運用ルール（今回の追加）

> **検証は「存在」ではなく「性質」で行う。**
> - ファイルを書いた → 全エントリの**実体**が `Path.exists()` で存在するか
> - 生成物を作った → 旧版と `cmp` で**差分がある**か。**サイズが同一なら置換の失敗を疑う**
> - 識別子を grep した → **定義行**があり、使用より前のセルにあるか（識別子の存在では不十分）
> - コピーした → src と dst の**サイズが一致**するか。`index + missing == target` で数が閉じるか
> - 下見モード（DRY_RUN）の出力を**本番ファイルに書かない**
> - **時系列データを読んだ → 単調性・重なり・桁を確認する**（assert が今回 2 度、汚染を止めた）
> - **スキーマは標本で決めない** → 全数走査で属性名を列挙する

**メタデータは仕様書ではなくデータで検証する** 工程を、Tier0 の前に置く。
CV の `kana` 列が全行空だった件と、まったく同じ種類の罠だった。
